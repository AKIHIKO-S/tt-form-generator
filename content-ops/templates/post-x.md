# テンプレ — X（Twitter）

> 編集担当が使う雛形。`tendency-analysis.md` のトーンに合わせて埋める。

## 単発ポスト
```
【フック / 1行目】（結論・数字・意外性で止める）

【本文】（1〜3行。1メッセージに絞る。改行で余白）

【CTA】（任意・1つだけ。例: 保存 / プロフのリンク / 続きは固定）

#ハッシュタグ（0〜2個）
```

## スレッド（連載・深掘り用）
```
1/ 【フック】このスレッドで分かること（結論先出し）

2/ 【背景・課題】

3/ 【中身①】

4/ 【中身②】

5/ 【まとめ＋CTA】（保存＆フォロー / プロフのリンクから〇〇）
```

## チェック
- [ ] 1行目で止まるか
- [ ] 1ポスト1メッセージか
- [ ] CTAは1つ・過剰でないか
- [ ] オーナーの語尾・文体か
- [ ] 140字（単発）/各ツイートの体裁に収まるか
