# テンプレ — note（記事・販売導線込み）

> 編集担当＋マーケ担当が使う雛形。無料/有料の境目はマーケ担当の設計に従う。

## 記事構成
```
【タイトル】（検索/興味で開かれる。ベネフィット or 好奇心）

【リード（導入）】
- 誰に向けた記事か
- この記事で得られること（結論先出し）
- 自己紹介は最小限

【本文：無料部分（信頼づくり）】
- 価値のある中身を出し惜しみせず
- 体験談・具体例で納得感
- 読者の悩みに寄り添う

────────── ここから有料 ──────────
（↑無料/有料の境目。ここで「この先の価値」を期待させる一文）

【本文：有料部分（変化・再現性）】
- 具体的な手順 / テンプレ / 事例
- 読者が再現できる形に
- 特典・補足

【まとめ＋次の一歩】
- 要点の再掲
- 関連note / 他媒体への導線
- 感想・フォローのお願い
```

## 販売設計メモ（マーケ担当）
- ターゲットの悩み:
- 無料部分のゴール（信頼）:
- 有料部分のゴール（変化）:
- 価格（根拠）:
- 特典/オファー:
- 流入元（X/IG/ブログのどのCTAから来るか）:

## チェック
- [ ] タイトルで開きたくなるか
- [ ] 無料部分だけでも満足＆信頼が生まれるか
- [ ] 有料の境目で期待が高まるか
- [ ] 価値提供:販売 = 8:2 を守れているか
- [ ] 流入元のCTAと整合しているか
