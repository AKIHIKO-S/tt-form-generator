# テンプレ — Instagram

> 編集担当が使う雛形。ビジュアル指示は具体的に（編集→デザイン/撮影に渡せるように）。

## カルーセル（図解・保存狙い）
```
【表紙（1枚目）】
  メインコピー:（短く強い言葉。スクロールを止める）
  ビジュアル指示:（背景色 / 写真 / 図のイメージ）

【2枚目〜（1枚=1メッセージ）】
  2:（小見出し＋一言）／ビジュアル指示
  3:（〃）
  4:（〃）

【最終枚】
  まとめ＋CTA:（保存してね / フォローで続き / プロフのリンク）
```

## キャプション
```
【1行目フック】（結論先出し・共感）

【本文】（結論→補足。改行で読みやすく）

【CTA】（保存 / コメント / プロフのリンクから無料note 等）

—
#ハッシュタグ（関連性重視で5〜15個）
```

## リール（任意）
```
冒頭2秒のフック:
見せる中身（箇条書き）:
締め＋CTA:
テロップ/BGMの方向性:
```
