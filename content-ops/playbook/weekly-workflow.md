# 週次運用フロー（Weekly Workflow）

秘書担当（`secretary`）がこのフローを司会進行する。オーナーは最後の決裁だけ。

## フロー図
```
[戦略責任者] 方針・柱を設定/更新（月次・四半期、必要時のみ）
      ↓
[リサーチ担当] 競合・トレンド調査（週次/隔週）
      ↓
[企画担当] ネタ出し → カレンダー素案（10〜20本→推奨5本）
      ↓
[編集担当] 媒体別に原稿作成・改善（A/B案）
      ↓
[マーケ担当] note導線・CTAを各原稿に組み込み
      ↓
[秘書担当] 全体を束ね「決裁パケット」を作成
      ↓
[オーナー] 最終判断（承認/修正）→ 公開・予約投稿
```

## 標準スケジュール（例）
| 曜日 | 内容 | 主担当 |
|---|---|---|
| 月 | リサーチ＋ネタ出し | リサーチ→企画 |
| 火 | 原稿作成 | 編集 |
| 水 | 導線/CTA付与＋決裁パケット作成 | マーケ→秘書 |
| 木 | **オーナー決裁** | オーナー |
| 木〜 | 修正反映・予約投稿セット | 編集→秘書 |
| 金〜日 | 公開・反応観察 | 秘書（記録） |
| 月 | 前週の振り返り（次週リサーチへ） | リサーチ |

## 秘書への定型指示
```
@secretary 今週のサイクルを回して。
今週は〔柱/テーマ〕を中心に、X 3本・IG 1本・ブログ 0本で。
最後に決裁パケットを出して。
```

## 月次/四半期
- 月初: 戦略責任者が方針の見直し要否を確認、KPIレビュー。
- 四半期頭: テーマ・KPIの再設定、note等オファーの見直し。
