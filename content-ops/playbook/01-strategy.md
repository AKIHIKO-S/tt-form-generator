# 01 — 戦略責任者（発信方針・方向性の設計）

担当エージェント: `strategy-lead`

## このドキュメントの役割
発信の「現行方針」を置く場所。戦略責任者がここを更新し、全担当がここを参照する。

## 方針設計のテンプレ

### 1. ポジショニング（一文）
> 〔誰〕に、〔何〕を、〔どんな立場〕で届ける。

### 2. ターゲットペルソナ
- 主要読者: 〔属性・状況〕
- 悩み/欲求: 〔解決したいこと・得たいこと〕
- 読了後の変化: 〔どう感じ、どう動いてほしいか〕

### 3. コンテンツの柱（ピラー 3〜5本）
| 柱 | 内容 | 主な媒体 |
|---|---|---|
| 柱A | | |
| 柱B | | |
| 柱C | | |

### 4. 媒体ごとの役割
- X: 入口・拡散
- Instagram: 世界観・信頼
- ブログ: 資産記事・検索流入
- note: 収益の出口

### 5. 四半期テーマ & KPI
- テーマ: 〔この3ヶ月で押し出すこと〕
- KPI: 〔フォロワー / 保存 / 流入 / note売上 など、追う指標を1〜3個〕
