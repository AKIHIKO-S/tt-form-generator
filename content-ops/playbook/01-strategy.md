# 01 — 戦略責任者（発信方針・方向性の設計）

担当エージェント: `strategy-lead`

## このドキュメントの役割
発信の「現行方針」を置く場所。戦略責任者がここを更新し、全担当がここを参照する。

## 方針設計のテンプレ

### 1. ポジショニング（一文）
> 〔誰〕に、〔何〕を、〔どんな立場〕で届ける。

### 2. ターゲットペルソナ
- 主要読者: 〔属性・状況〕
- 悩み/欲求: 〔解決したいこと・得たいこと〕
- 読了後の変化: 〔どう感じ、どう動いてほしいか〕

### 3. コンテンツの柱（ピラー 3〜5本）
| 柱 | 内容 | 主な媒体 |
|---|---|---|
| 柱A | | |
| 柱B | | |
| 柱C | | |

### 4. 媒体ごとの役割
- X: 入口・拡散
- Instagram: 世界観・信頼
- ブログ: 資産記事・検索流入
- note: 収益の出口

### 5. 四半期テーマ & KPI
- テーマ: 〔この3ヶ月で押し出すこと〕
- KPI: 〔フォロワー / 保存 / 流入 / note売上 など、追う指標を1〜3個〕

## 現行方針（最新を上に追記）

### 2026-06-25 初稿ドラフト（戦略責任者）— 要オーナー承認
> サンプル5件（`tendency-analysis.md`）をもとにした**たたき台**。確定はオーナー判断。

**1. ポジショニング（一文）**
> 北海道・釧路の「空と自然」を望遠で切り取り、被写体と人へのリスペクトを温かく伝える写真クリエイター。
> 飛行機・野鳥・地域イベントを、マニアックな豆知識と物語で“専門性×親しみ”に翻訳して届ける。

**2. ターゲットペルソナ**
- 主要読者: 航空ファン／野鳥・自然写真好き／カメラ(Sony望遠)ユーザー／釧路・北海道に縁のある人
- 悩み/欲求: 美しい瞬間・知らなかった舞台裏を知りたい、地域の魅力に触れたい、撮影のヒントが欲しい
- 読了後の変化: 「現地に行きたい/撮りに行きたい」「続きが見たい」「この人から学びたい・買いたい」

**3. コンテンツの柱（4本・暫定）**
| 柱 | 内容 | 主な媒体 |
|---|---|---|
| 空（航空） | 釧路空港、空自/編隊飛行、空港ツアー・裏側、パイロットとの交流 | IG / X / note |
| 生きもの（野鳥・自然） | オオジシギ/タンチョウ/氷の造形など釧路の自然＋生態の豆知識 | IG / ブログ |
| 地域・つながり | 空港イベント、マラソン撮影班、参加者・スタッフとの物語と感謝 | X / IG |
| 撮影・AIクリエイト | 機材・撮影術・AI活用の裏側、作品の作り方 | ブログ / note |

**4. 媒体ごとの役割**
- X: 入口・速報・日常とユーモア（人柄でファン化、IG/noteへ送客）
- Instagram: 作品性・世界観（保存される写真＋物語、発見流入をハッシュタグで強化）
- ブログ/Web: 資産記事（撮影記・釧路フォトガイド・野鳥図鑑でSEO/ストック）
- note: 収益の出口（写真販売、撮影術、釧路フォト体験ガイド、有料マガジン）

**5. 今四半期テーマ & KPI（暫定）**
- テーマ: 「**釧路の空と自然**」を連載化し、CTA・note導線をゼロから設計する（伸びしろの3点を埋める）
- KPI候補（1〜3個に絞る）: IG保存数 / プロフからのリンククリック / note登録・初売上

**オーナーへの確認ポイント**:
- 柱は4本でよいか（「撮影・AIクリエイト」を出すか、写真作品に寄せるか）
- 収益化のゴール（何を売りたいか: 写真 / 撮影術 / 体験ガイド / 法人撮影依頼 など）
- 卓球（釧路卓球協会）の発信はこのチームの対象に含めるか別運用か
