# 01 — 戦略責任者（発信方針・方向性の設計）

担当エージェント: `strategy-lead`

## このドキュメントの役割
発信の「現行方針」を置く場所。戦略責任者がここを更新し、全担当がここを参照する。

## 方針設計のテンプレ

### 1. ポジショニング（一文）
> 〔誰〕に、〔何〕を、〔どんな立場〕で届ける。

### 2. ターゲットペルソナ
- 主要読者: 〔属性・状況〕
- 悩み/欲求: 〔解決したいこと・得たいこと〕
- 読了後の変化: 〔どう感じ、どう動いてほしいか〕

### 3. コンテンツの柱（ピラー 3〜5本）
| 柱 | 内容 | 主な媒体 |
|---|---|---|
| 柱A | | |
| 柱B | | |
| 柱C | | |

### 4. 媒体ごとの役割
- X: 入口・拡散
- Instagram: 世界観・信頼
- ブログ: 資産記事・検索流入
- note: 収益の出口

### 5. 四半期テーマ & KPI
- テーマ: 〔この3ヶ月で押し出すこと〕
- KPI: 〔フォロワー / 保存 / 流入 / note売上 など、追う指標を1〜3個〕

## 現行方針（最新を上に追記）

### 2026-06-25 初稿ドラフト（戦略責任者）— 要オーナー承認
> サンプル5件（`tendency-analysis.md`）＋オーナー回答をもとにした**たたき台**。確定はオーナー判断。
> **軸足: 写真作品に寄せる**（AIは前面に出さず裏方扱い）。**卓球＝対象外（別運用）**。

**1. ポジショニング（一文）**
> 北海道・釧路の「空と自然」を望遠で切り取り、被写体と人へのリスペクトを温かく伝える写真家。
> 飛行機・野鳥・地域の一瞬を、マニアックな豆知識と物語で“専門性×親しみ”として届ける。

**2. ターゲットペルソナ**
- 主要読者: 航空ファン／野鳥・自然写真好き／カメラ(Sony望遠)ユーザー／釧路・北海道に縁のある人
- 悩み/欲求: 美しい瞬間・知らなかった舞台裏を知りたい、地域の魅力に触れたい、撮り方を学びたい、撮影を依頼したい
- 読了後の変化: 「現地に行きたい/撮りに行きたい」「続きが見たい」「この人から学びたい・買いたい・頼みたい」

**3. コンテンツの柱（写真作品中心・4本／暫定）**
| 柱 | 内容 | 主な媒体 |
|---|---|---|
| 空（航空写真） | 釧路空港、空自/編隊飛行、空港ツアー・裏側、パイロットとの交流 | IG / X / note |
| 生きもの（野鳥・自然） | オオジシギ/タンチョウ/氷の造形など釧路の自然＋生態の豆知識 | IG / ブログ |
| 地域・つながり | 空港イベント、撮影現場、参加者・スタッフとの物語と感謝 | X / IG |
| 撮影術（学び） | 望遠・野鳥・航空の撮り方／現場の工夫。※AI活用は“裏方の道具”として控えめに触れる | ブログ / note |

> 「AI」は独立柱にしない。肩書き「AIクリエイター」は維持しつつ、**作品と撮影術を主役**にし、AIは制作の裏側として時々見せる程度。

**4. 媒体ごとの役割**
- X: 入口・速報・日常とユーモア（人柄でファン化、IG/noteへ送客）
- Instagram: 作品性・世界観（保存される写真＋物語、発見流入をハッシュタグで強化）
- ブログ/Web: 資産記事（撮影記・釧路フォトガイド・野鳥図鑑・撮影術でSEO/ストック）
- note: 収益の出口（後述の3本立て）

**5. 収益化ゴール（3本立て）と今四半期テーマ・KPI**
収益の出口（マーケ担当が `05-marketing.md` で導線設計）:
1. **撮影術・ノウハウ**（有料note／ミニ講座）— 望遠・野鳥・航空の撮り方
2. **写真・プリント販売**（note／BASE等）— 作品・カレンダー・プリント
3. **撮影依頼（法人）**— 空港/自治体/イベントの撮影を受ける入口（問い合わせ導線）

- 今四半期テーマ: 「**釧路の空と自然**」を連載化し、**CTA・note導線をゼロから設計**（伸びしろ3点を埋める）
- KPI候補（1〜3個に絞る）: IG保存数 / プロフからのリンククリック / 出口の初成果（note登録・プリント初売上・撮影依頼の問い合わせ件数）

**オーナーへの確認ポイント**:
