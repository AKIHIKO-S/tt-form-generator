# 02 — リサーチ担当（競合分析・市場調査）

担当エージェント: `researcher`

## 調査の観点リスト
着手時はこのリストを上から確認する。

### 競合・参考アカウント
- 同ジャンルで伸びている発信者は誰か（3〜5アカウント）
- 伸びている投稿の「型」は何か（スレッド/図解/体験談/比較 等）
- 投稿頻度・時間帯・媒体の使い分け
- フォロワーが反応しているポイント（保存/引用/コメントの傾向）

### 市場・読者
- 読者が検索している悩み/キーワード
- 季節性・時事ネタ（カレンダー要因）
- 需要はあるが供給が薄い「隙間」テーマ

### フォーマット
- X: スレッド型 / 単発 / 画像付き、どれが伸びているか
- Instagram: 保存される型（図解カルーセル、リール）
- ブログ: 検索意図に対する構成、上位記事の見出し
- ハッシュタグ/キーワードの当たり所

## 出力フォーマット（リサーチメモ）
```
## YYYY-MM-DD リサーチ: 〔テーマ〕
- 競合/参考:
  - @account — 伸びた投稿の型（URL）
- トレンド/季節ネタ:
- 有効フォーマット（媒体別）:
- キーワード/ハッシュタグ候補:
- 企画担当への示唆（3〜5本）:
```

## ルール
- **出典URLを必ず残す**。数字は出典付き、無ければ「要検証」。
- 真似ではなく「自分の柱に翻訳できる材料」を出す。
