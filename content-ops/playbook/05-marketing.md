# 05 — マーケティング担当（note導線・販売設計）

担当エージェント: `marketer`

## 基本ファネル

```
[X / Instagram]  認知・興味
      │  プロフィール / 固定投稿 / ストーリーズ / リンク
      ▼
[Webサイト・ブログ / 無料note]  信頼・教育
      │  記事内CTA / メール・LINE登録 / 関連リンク
      ▼
[有料note]  販売・収益
      │  オファー / 価格 / 特典
      ▼
[購入・リピート]
```

## CTAパターン（媒体別）
- **X**: 「プロフのリンクから〇〇」「このスレッドが役立ったら保存＆フォロー」「続きは固定の記事で」
- **Instagram**: 「保存して見返してね」「プロフのリンクから無料note」「DMで〇〇と送って」
- **ブログ**: 記事末に関連noteへの内部リンク、メルマガ/LINE登録、まとめ記事への回遊
- **note**: 無料部分の最後に「ここから先」で価値の境目を作る、関連有料noteへの導線

## note設計テンプレ
```
タイトル案:
ターゲットの悩み:
無料部分で渡す価値（信頼づくり）:
有料部分の中身（変化/再現性）:
無料/有料の境目（どこで切るか）:
価格（根拠）:
特典/オファー:
販売後の次の一歩（リピート設計）:
```

## バランス原則
- 価値提供 : 販売 ＝ おおむね **8 : 2**。
- まず信頼、次に提案。押し売りはブランドを毀損する。
- 価格・オファーの確定は**オーナーの最終判断**。根拠付きで推奨する。

### 2026-06-25 初稿（マーケ担当）— 要オーナー承認
> 軸足は写真作品。収益の出口は**3本立て**（撮影術ノウハウ / 写真・プリント販売 / 法人撮影依頼）。
> まず作品で信頼を作り、各出口へ自然に橋渡しする。

**共通の入口設計**
- X/IG プロフィール: 一言で「釧路の空と自然を撮る写真家」＋リンク（リンク集 or サイト）
- IG ハイライト/固定: 「撮影術note」「プリント購入」「撮影のご依頼」の3導線を常設
- 各投稿の締めに、被写体に応じて1つだけCTAを置く（盛り込みすぎない）

**出口①: 撮影術・ノウハウ（有料note / ミニ講座）**
```
作品投稿（IG/X）→「どう撮ったか」の無料解説（スレッド/キャプション/ブログ）
  → 体系版を有料noteへ（例:「釧路で野鳥を撮る｜望遠の設定と待ち方」）
```
- 無料で“考え方”、有料で“再現できる手順・設定値・現場判断”。
- CTA例: 「設定と作例の全部はnoteにまとめました📷」

**出口②: 写真・プリント販売（note / BASE 等）**
```
作品投稿で反応 →「プリントしました/販売中」の告知 → 販売ページへ
```
- カレンダー、A3プリント、ポストカード等。季節・限定で動機づけ。
- CTA例: 「この一枚、プリント販売しています。詳細はプロフのリンクから」

**出口③: 撮影依頼（法人）**
```
空港/イベント/自治体の撮影実績を作品＋裏側として発信
  → 「撮影のご依頼」ページ（実績・対応範囲・問い合わせ）へ
```
- 信頼の核は“実績の見える化”。撮影班・公式ツアーの実例を実績ページに集約。
- CTA例: 「撮影のご依頼はプロフのリンク先から承っています」

**バランス**: 価値提供:販売 = 8:2。出口は1投稿に1つまで。

**要確認（オーナー）**: プリント販売の置き場（note/BASE/他）、法人依頼の問い合わせ先・実績ページの所在、リンク集ツール（lit.link/プロフのリンク等）。
