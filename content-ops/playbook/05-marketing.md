# 05 — マーケティング担当（note導線・販売設計）

担当エージェント: `marketer`

## 基本ファネル

```
[X / Instagram]  認知・興味
      │  プロフィール / 固定投稿 / ストーリーズ / リンク
      ▼
[Webサイト・ブログ / 無料note]  信頼・教育
      │  記事内CTA / メール・LINE登録 / 関連リンク
      ▼
[有料note]  販売・収益
      │  オファー / 価格 / 特典
      ▼
[購入・リピート]
```

## CTAパターン（媒体別）
- **X**: 「プロフのリンクから〇〇」「このスレッドが役立ったら保存＆フォロー」「続きは固定の記事で」
- **Instagram**: 「保存して見返してね」「プロフのリンクから無料note」「DMで〇〇と送って」
- **ブログ**: 記事末に関連noteへの内部リンク、メルマガ/LINE登録、まとめ記事への回遊
- **note**: 無料部分の最後に「ここから先」で価値の境目を作る、関連有料noteへの導線

## note設計テンプレ
```
タイトル案:
ターゲットの悩み:
無料部分で渡す価値（信頼づくり）:
有料部分の中身（変化/再現性）:
無料/有料の境目（どこで切るか）:
価格（根拠）:
特典/オファー:
販売後の次の一歩（リピート設計）:
```

## バランス原則
- 価値提供 : 販売 ＝ おおむね **8 : 2**。
- まず信頼、次に提案。押し売りはブランドを毀損する。
- 価格・オファーの確定は**オーナーの最終判断**。根拠付きで推奨する。
