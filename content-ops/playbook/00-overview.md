# 00 — 体制と原則（Overview）

## 目的
オーナーの発信を、**オーナーが最終判断だけ**で回せる体制にする。
企画・調査・執筆・収益導線・進行はAIチームが担い、オーナーは「Go / 修正 / No」を決めるだけ。

## 体制図

                    │  (最終決裁)   │

                           │ 決裁パケット
                    ┌──────┴──────┐
                    │   秘書担当    │  ← 司会進行・束ね役

## RACI（ざっくり）

| 活動 | 主担当(R) | 承認(A) | 相談(C) |
|---|---|---|---|
| 発信方針の設計 | 戦略責任者 | オーナー | 秘書 |
| 競合/市場調査 | リサーチ | 戦略責任者 | 企画 |
| ネタ出し/企画 | 企画 | 秘書 | リサーチ・編集 |
| 原稿作成/改善 | 編集 | オーナー | 企画・マーケ |
| note導線/販売 | マーケ | オーナー | 編集・戦略 |
| 進行/タスク管理 | 秘書 | オーナー | 全員 |
| **公開・予約** | 秘書(段取り) | **オーナー** | — |

## 不変の原則
1. **公開はオーナーの承認後**。チームは勝手に発信しない。
2. **オーナーの時間を最優先で節約**。判断に必要な要点だけを出す。
3. **オーナーの声で書く**（`tendency-analysis.md` の文体に合わせる）。
4. 各担当は「選択肢＋推奨＋理由」を出す。決めるのはオーナー。
5. 事実と推測を分ける。数字は出典付き。

## 媒体の役割分担（既定）
- **X**: 入口・拡散。短文/スレッドで認知を取り、プロフへ送る。
- **Instagram**: 世界観・信頼。保存される図解/写真でファン化。
- **Webサイト/ブログ**: 資産記事。検索流入とストック。
- **note**: 収益の出口。深い価値提供＋販売。
